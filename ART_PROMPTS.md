# Bank Run: AI Image Prompts

Copy any prompt into ChatGPT, Grok, Midjourney, or another image tool. Every
prompt already includes the style, so each one works on its own.

## How to keep every image in the same style
1. **Make #1 (key art) or #3 (main street) first.** Regenerate until you love
   the look.
2. **Attach that image to every later prompt** and add: *"Match the art style
   of the attached image exactly."*
   - ChatGPT and Grok: attach the image, or stay in the same chat.
   - Midjourney: add `--sref <image URL>` to the end of the prompt.
3. **For characters:** generate one you like, then ask for *"the same
   character"* in new poses.
4. **For game pieces** (buildings, items, characters), ask for a
   **transparent background** if the tool offers it (ChatGPT does).
5. Don't add "in the style of Red Dead" or any real artist's name. That keeps
   the art original and avoids copyright problems.

**Team colors (keep these consistent, since players need to tell sides apart
at a glance):**
- **Lawmen:** navy blue and silver
- **Outlaws:** red bandanas and black
- **Neutral** (prospectors, traders): tan and sage green
- **Gold:** always bright shiny yellow-gold, so loot stands out

## What AI art is good for (and not)
- **Great for:** key art, the logo, concept art, backgrounds, buildings, item
  icons, the wanted poster, and UI mockups. Many of these can be used almost
  directly.
- **Weak at:** matching sprite sheets for walking, shooting, and riding
  animations. AI tools rarely keep a character identical across frames. For
  the moving characters, I'll start with simple placeholder sprites I make in
  code, and we can swap in proper sprites later (a sprite tool or a pixel
  artist).
- **Bring the images back here** and I'll use them as the reference for the
  game's look.
